usage: pipeline_training_run.py [-h] --model {nano,olmo3_32b,olmo3_7b,super,ultra} --mode {sft,cpt,pretrain}
                                [--config-file CONFIG_FILE] [--peft PEFT] [--disable-ft] [--disable-straggler]
                                [--enable-pao]

Unified training: SFT, CPT, and from-scratch pretraining for the models of RECIPE_MAP

options:
  -h, --help            show this help message and exit
  --model {nano,olmo3_32b,olmo3_7b,super,ultra}
                        Model variant (every model that has a recipe in pipeline/training/recipes.py)
  --mode {sft,cpt,pretrain}
                        Training mode
  --config-file CONFIG_FILE
                        Path to the YAML OmegaConf override file.
  --peft PEFT           Type of PEFT to use (SFT mode only)
  --disable-ft          Disable fault tolerance and straggler detection
  --disable-straggler   Disable NVRx straggler detection only, keeping fault tolerance (ft_launcher restarts) enabled
  --enable-pao          Enable Precision-Aware Optimizer (BF16 momentum/variance, halves optimizer memory)
